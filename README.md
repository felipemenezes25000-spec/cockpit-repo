# Cockpit — Consultório Dra. Érika Passos

Sistema de gestão da clínica: agenda, pacientes, prontuários, documentos,
financeiro, relacionamento e indicadores em um só lugar.

**Etapa 1** — estrutura navegável e tela Visão Geral, com dados inteiramente
fictícios. Sem banco de dados, autenticação ou integrações externas.

## Executar

```bash
npm install
npm run dev
```

A aplicação abre em <http://localhost:3000>.

## Comandos

| Comando | O que faz |
|---|---|
| `npm run dev` | Servidor de desenvolvimento |
| `npm run build` | Build de produção |
| `npm start` | Sobe o build de produção |
| `npm run lint` | ESLint |
| `npm run typecheck` | Verificação de tipos |
