# Cockpit — o sistema completo (vídeo)

`cockpit-o-sistema-completo.mp4` — 7min59, 1080p, narrado em pt-BR, com legenda
na imagem, trilha e motion graphics. Mostra o sistema tela a tela: acesso e
perfis, Visão Geral, Agenda, Pacientes, Prontuários, Financeiro (vendas,
recebimentos, despesas e fluxo), Documentos e assinatura pelo celular,
Relacionamento, Busca e Configurações, um dia na clínica, segurança e os
ganhos para a clínica.

`cockpit-o-sistema-completo.srt` — as mesmas legendas em arquivo separado,
para subir junto em YouTube, Instagram e afins.

As telas foram capturadas do build de produção rodando contra o Supabase
**local**, só com os dados de demonstração do seed (pacientes, valores e
agendamentos fictícios).

Esta pasta fica fora do deploy (`.vercelignore`).
